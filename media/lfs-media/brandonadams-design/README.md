# Brandon Adams — ASI & Mobius work

Archived on 2026-11-22 from [brandonadams.design](https://www.brandonadams.design/), the portfolio of Brandon Adams, a designer I worked with at ASI (Autonomous Solutions Inc.).

Images are the largest versions on the site’s CDN (`cdn.brandonadams.design`). The site only serves full-size files and `_sm` thumbnails, so these are the full-size files. Video projects were YouTube embeds; this archive has the links and the largest available thumbnail, not the video files.

All text comes from each post’s WordPress excerpt and body. The pages themselves show only the title, date and category. The same data is in `projects.json`.

## ASI Mobius Vehicle Gauges

- **Date:** 2016-02-11
- **Category:** UX
- **Original:** <https://www.brandonadams.design/asi-gauges/>

As a part of the ASI Mobius platform, each vehicle has a set of gauges that deliver real time feedback about the status of the system. I created several different gauges that could be mixed and matched with any given vehicle and connected to any available telemetry data item.
